TRADEGUARD — ZIP → APK (ONE-CLICK STYLE)
=========================================

এই project-এ GitHub Actions build workflow আগে থেকেই দেওয়া আছে।
Gradle wrapper JAR না থাকলেও GitHub নিজে Gradle 8.10.2 সেটআপ করে APK build করবে।

যেভাবে ব্যবহার করবেন:

1) GitHub.com-এ login করুন।
2) New repository তৈরি করুন। উদাহরণ: tradeguard-android
3) এই ZIP extract করুন। ভিতরের TradeGuard folder-এর সব file repository-তে upload করুন।
   Repository-র root-এ অবশ্যই TradeGuard folder এবং তার ভিতরের .github folder থাকবে।
4) GitHub-এর Actions tab খুলুন।
5) "Build TradeGuard APK" workflow নির্বাচন করুন।
6) "Run workflow" চাপুন।
7) Build শেষ হলে ওই workflow run খুলুন।
8) Artifacts অংশ থেকে "TradeGuard-APK" download করুন।
9) ZIP খুললে TradeGuard-debug.apk পাবেন।

নোট:
- প্রথম push-এও workflow automatic build হবে।
- পরে শুধু Actions → Build TradeGuard APK → Run workflow করলেই নতুন APK তৈরি হবে।
- এটি debug APK; commercial release-এর আগে নিজের signing key দিয়ে release build করতে হবে।
- HTML UI + Android native functionality এই project-এ রাখা হয়েছে।
- Accessibility, MediaProjection, ML Kit OCR এবং Quotex foreground lock-এর native অংশ বাদ দেওয়া হয়নি।
